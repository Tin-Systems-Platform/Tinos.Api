# Tinos.Api
This the official documentation for the Tinos.Api project. Here you will find information on how to get started, usage examples, and detailed API references.

## Why Tinos.Api?
Tinos.Api is designed to provide helpers and APIs for building apps for Tinos. 

It simplifies common tasks, provides a consistent interface, and helps developers to focus on building features rather than dealing with boilerplate code.

Providing a set of methods and utilities, Tinos.Api aims to enhance productivity and streamline the development process for Tinos applications.

## Modules

Tinos.Api is organized into several modules, each serving a specific purpose. The following modules are currently available:

- **Tinos.Api.Common**: Contains common interfaces, utilities, and helpers shared across different modules.
- **Tinos.Api.Shell**: Provides shell-related functionality, including command registration, command execution, and extensible command-line interfaces.
