# Tinos.Api

Tinos.Api is a library that provides a collection of APIs for developing applications and operating-system components on top of the Cosmos operating system.

Originally planned as part of the Tinos project, Tinos.Api was separated into its own repository to make the APIs easier to reuse, maintain, and distribute across different Tinos projects.

## Features

- **Version Management:** Utilities for representing, parsing, and managing version numbers.
- **Partition Management:** Basic disk partition management functionality, with additional features planned.
- **More to come:** Additional APIs and functionality are planned. See [TODO.md](TODO.md) for the development roadmap.

## Documentation

This project includes documentation covering the available APIs and how to use them when developing applications and operating-system components for Cosmos.

Documentation is generated using [DocFX](https://dotnet.github.io/docfx/) and the documentation source files are available in the `docs` directory.
